# KIS Construction portfolio

Static HTML, CSS and JavaScript website. GitHub Pages serves the root of the main branch; no build step is required.

The site presents KIS Construction, its own residential developments, and Knightswood Estate in Sandown. It does not advertise outside contracting services or collect project leads.

The six-stage construction sequence blends generated architectural images. It is a plan-based visualisation, not historical footage or a survey-accurate 3D model. Real estate photographs include visible source credits. The KIS branding and corporate contact details come from the supplied company signature.

For local preview run `python3 -m http.server 4173` in this directory.
